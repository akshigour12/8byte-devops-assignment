8Byte DevOps Assignment

A DevOps and DevSecOps implementation on AWS using Terraform, GitHub Actions, Docker, Amazon ECR, EC2, ALB, RDS PostgreSQL, AWS Systems Manager, and CloudWatch.

Project Overview

The project demonstrates:

Infrastructure provisioning with Terraform

AWS VPC with public and private subnets

EC2-based Docker application deployment

Application Load Balancer

RDS PostgreSQL in private subnets

Amazon ECR image storage

GitHub Actions CI/CD

AWS IAM OIDC authentication

Automated security scanning

Staging deployment and manual production approval

CloudWatch monitoring and centralized logging

RDS backups and AWS Secrets Manager

Infrastructure

AWS region:

ap-south-1

Network:

VPC: 10.0.0.0/16

2 public subnets

2 private subnets

Internet Gateway

No NAT Gateway, to control assignment cost

Security groups restrict:

Internet → ALB on ports 80/443

ALB → application on port 5000

Application → PostgreSQL on port 5432

The RDS instance is not publicly accessible.

GitHub Actions authenticates to AWS through OIDC instead of long-lived AWS access keys.

Monitoring and Logging

Two CloudWatch dashboards are configured:

8Byte-Infrastructure

8Byte-Application

Infrastructure monitoring includes EC2 CPU, memory, disk, and RDS metrics.

Application monitoring includes request count, 4xx/5xx responses, latency, and target health.

Centralized log groups:

/8byte-devops/application
/8byte-devops/system

Security and Backup

Security controls include:

IAM least-privilege-oriented access

GitHub OIDC

IMDSv2

Private RDS

Restricted security groups

Non-root Docker container

SAST and dependency scanning

Container vulnerability scanning

Secret scanning

Encrypted Terraform state

Encrypted RDS storage

RDS automated backups are configured with 1-day retention.

Database credentials are generated by Terraform and stored in AWS Secrets Manager.

Setup

git clone https://github.com/akshigour12/8byte-devops-assignment.git
cd 8byte-devops-assignment

cd terraform
terraform init
terraform validate
terraform plan

Application tests:

cd app
pip install -r requirements.txt
pytest -v

Docker test:

docker build -t 8byte-devops-app ./app
docker run --rm -p 5000:5000 8byte-devops-app
